# 🔗 FreeLinkGrabber

**FreeLinkGrabber** is a lightweight Chrome extension for quickly collecting URLs from selected areas of webpages.

## ✨ Features

- 🔗 Select an area and grab URLs
- 📜 Auto-scroll while dragging
- ☑️ Select or clear individual URLs
- 🚀 Open selected URLs in new tabs
- 📋 Copy selected URLs
- ⬇️ Download URLs as `.txt`
- 🎨 Clean, colorful interface
- 👁️ Custom FreeLinkGrabber logo

## 🚀 Installation

1. Download and extract the extension ZIP.
2. Open `chrome://extensions/`
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the extracted `FreeLinkGrabber-extension` folder.

## 🖱️ Usage

1. Open a webpage containing links.
2. Click **🔗 Grab URLs**.
3. Drag over the area containing the links.
4. Move near the top/bottom edge to auto-scroll.
5. Release the mouse.
6. Select the URLs you want.
7. Use **Open Selected**, **Copy Selected**, or **Download TXT**.

> ⚠️ Chrome restricts extensions from running on certain pages such as `chrome://` pages and the Chrome Web Store.
